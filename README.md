OrbitGuard AI 🚀
AI-assisted collision-risk assessment for Low Earth Orbit satellites
OrbitGuard AI helps identify risky satellite–debris close approaches and compare potential collision-avoidance options using orbital analysis, explainable AI, and simulation.
The Problem
Crowded Low Earth Orbit increases the risk of satellite collisions. Uncertain orbital data makes it difficult to decide when to manoeuvre, while unnecessary manoeuvres waste fuel.
Our Solution
OrbitGuard AI aims to:
- Screen satellite–debris close approaches.
- Assess risk and highlight uncertainty.
- Explain risk predictions using XAI techniques such as SHAP.
- Compare simulated avoidance options by residual risk and estimated fuel cost.
- Display ranked alerts and insights on a dashboard.
How It Works
Orbital Data → Close-Approach Screening → AI Risk Assessment → Explainability → Manoeuvre Simulation → Dashboard
Hackathon Focus
We aim to demonstrate whether explainable, uncertainty-aware risk assessment can support better avoidance decisions than a simple risk-threshold approach.
Tech Stack
Python · NumPy · pandas · scikit-learn/XGBoost · SHAP · Plotly/Streamlit
Final tools depend on the implemented prototype.
